# SME Ally website (smeally.com)

Plain website files. No build step. Vercel serves them as they are.

## The 3 things you will edit

| What | Where | How |
|---|---|---|
| Your photo | `images/ime.jpg` | Upload a portrait photo into the `images` folder named exactly `ime.jpg`. Until then the gold mark shows. |
| Form key and booking link | `js/config.js` | Paste your Web3Forms key and your Cal.com link between the quote marks. |
| Demo video | `index.html` | Search the file for `DEMO VIDEO` and follow the 4 steps written there. |

## Pages

- `index.html` Home
- `what-we-do.html` What we do
- `about.html` About
- `start.html` Get started form and booking calendar
- `privacy.html` Privacy notice
- `404.html` Shown when a link is wrong

## Never upload

Passwords, API keys other than the Web3Forms key, `.env` files, or customer data.
